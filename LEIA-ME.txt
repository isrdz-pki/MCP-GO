AGENTE GO 1.0 - Relatório de vendas e consulta de pedidos do Gestão Online
=========================================================================

Não precisa instalar nada (nem Python, nem bibliotecas). Basta extrair e abrir.


1. COMO INSTALAR
----------------
1. Extraia o .zip numa pasta sua, por exemplo:  Documentos\Agente GO
   (não rode de dentro do .zip, e não apague a pasta "_internal": o programa precisa dela).
2. Dê dois cliques em  "Agente GO.exe".
3. Dica: clique com o botão direito no "Agente GO.exe" > Mostrar mais opções >
   Enviar para > Área de trabalho (criar atalho).

Se o Windows mostrar "O Windows protegeu o computador" (SmartScreen):
clique em "Mais informações" > "Executar assim mesmo". Isso acontece porque o
programa é interno e ainda não foi assinado digitalmente.


2. TOKEN DE ACESSO (faça isso antes de tudo)
--------------------------------------------
O programa usa o SEU acesso ao GO. Ele não pede usuário e senha: usa o "token"
que o GO cria quando você faz login no navegador.

1. Abra o GO no navegador (Edge ou Chrome) e faça login normalmente.
2. Tecle F12 e clique na aba "Console".
3. No Agente GO, clique em "Copiar comando" e cole no Console. Tecle Enter.
   (Se o navegador pedir, digite  allow pasting  e tecle Enter antes de colar.)
4. O token foi para a área de transferência. Cole no campo "Token" do Agente GO
   e clique em "Salvar". Use "Testar" para conferir.

O token vale cerca de 12 horas. Quando vencer, o programa avisa: é só repetir os
passos acima. O token fica guardado no Cofre de Credenciais do Windows, só no
seu usuário. Não compartilhe o seu token: ele dá acesso ao GO em seu nome.


3. O QUE O PROGRAMA FAZ
-----------------------
Aba "Relatório de vendas"
  - Baixa o relatório "CSV - Vendas por unidade" em Excel (.xlsx).
  - Escolha o período (ou use os atalhos: Hoje, Ontem, Este mês, Mês passado...).
  - Unidade: 52 = E-commerce - Soluti. Use "Conferir" para ver o nome de um
    código, ou "Listar" para escolher pela lista. Vazio = todas as unidades.
  - O arquivo vai para a pasta Downloads (dá para trocar em "Alterar pasta").
  - Períodos longos podem levar alguns minutos.

Aba "Pedido"
  - Consulta um pedido pelo número (10 dígitos, ex.: 7884122078).
  - "Baixar NF" salva os anexos do pedido (NF/DANFE, XML) em Downloads.

Aba "CPF / CNPJ"
  - Lista todas as compras de um cliente e os dados cadastrais dele.
  - Dá para baixar a NF de cada compra e salvar a lista em Excel.

Aba "Lote (planilha)"
  - Selecione uma planilha .xlsx com uma coluna de números de pedido.
  - O programa consulta todos e gera uma planilha nova com os detalhes,
    na mesma ordem. Pedido não encontrado vem marcado na coluna Observação.


4. PROBLEMAS COMUNS
-------------------
"O GO recusou o token"        -> o token venceu. Pegue um novo (seção 2).
"Não consegui gravar o arquivo" -> feche a planilha com o mesmo nome no Excel.
"O GO não devolveu uma planilha" -> tente de novo; se repetir, avise o suporte
                                   com o texto da mensagem.


5. USO AVANÇADO (opcional) - rodar sem abrir a janela
-----------------------------------------------------
Útil para o Agendador de Tarefas. Usa o token salvo pela janela:

  "Agente GO.exe" --relatorio 01/10/2026 31/10/2026 --unidade 52
  "Agente GO.exe" --relatorio 01/10/2026 31/10/2026 --unidade 52 --saida "C:\pasta\arquivo.xlsx"

O resultado fica registrado em  %LOCALAPPDATA%\Agente GO\agente_go.log
Código de saída: 0 = ok, 1 = erro, 2 = sem token salvo, 3 = token vencido.
Lembre: o token vence a cada 12 h, então a execução agendada só funciona
enquanto houver um token válido salvo.
